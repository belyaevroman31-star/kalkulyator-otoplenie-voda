# Калькулятор системы отопления и водоснабжения (PWA)

Офлайн-приложение «Калькулятор системы отопления и водоснабжения» от BELYAEV_PROJECT.
Работает без интернета, устанавливается на Android и iPhone («Добавить на главный экран»).

Папка содержит готовый к публикации набор файлов: приложение, манифест PWA, иконки,
service worker (кэширует всё для офлайн) и функции синхронизации смет в репозиторий GitHub.

## Что в папке

| Файл | Назначение |
| --- | --- |
| `index.html`, `app.js`, `оболочка.css`, `calc.css` | Приложение |
| `prices_local.js`, `boilers_local.js` | Актуальный прайс от 22.04.2026 |
| `manifest.webmanifest` | Манифест PWA (нужен для установки на устройства) |
| `service-worker.js` | Офлайн-кэш приложения |
| `icon-192.png`, `icon-512.png`, `icon-180.png`, `icon-64.png` | Иконки |

## Публикация приложения (шаг 1: репозиторий сайта)

1. На https://github.com создайте новый репозиторий, например `kalkulyator-otoplenie-voda`
   (можно приватный — Pages работает и для приватных).
2. Перейдите в репозиторий → **Add file → Upload files** и перетащите ВСЕ файлы из этой
   папки (они должны лежать в корне репозитория, не во вложенной папке).
3. **Settings → Pages** → Source: *Deploy from a branch* → ветка `main`, папка `/root` → Save.
4. Через минуту приложение будет доступно по адресу `https://<ваш-логин>.github.io/kalkulyator-otoplenie-voda/`.

## Хранение смет (шаг 2: репозиторий-хранилище)

1. Создайте второй репозиторий, например `smeti-otoplenie-voda` (**рекомендуется приватный**).
   Создавать какие-либо файлы в нём не нужно — приложение само создаст папку `smeti/`.
2. Настройте токен GitHub:
   - GitHub → Settings → Developer settings → **Personal access tokens → Tokens (classic)** → Generate new token.
   - Права (classic): отметьте `repo` (или используйте *fine-grained* токен, ограниченный
     только репозиторием `smeti-otoplenie-voda`, с правами **Contents: Read and write**).
3. В приложении откройте **Справка → «Синхронизация смет с репозиторием GitHub»** и укажите:
   - токен,
   - ваше имя пользователя GitHub,
   - имя репозитория для смет (например `smeti-otoplenie-voda`).
   Токен хранится только на вашем устройстве (в localStorage) и передаётся только в GitHub API.
4. Кнопки отправки смет в репозиторий:
   - в расчёте: **«Сохранить + в репозиторий»** — сохраняет в историю и сразу отправляет .xls;
   - в истории: открыв смету — кнопка **«В репозиторий»**.

Сметы сохраняются в файл `smeti/<ФИО>_<телефон>.xls` (повторная загрузка того же клиента
обновляет тот же файл). Скачать их можно прямо с сайта GitHub в этом репозитории.

## Установка на телефон

Первый запуск делайте при подключении к интернету (кэширование офлайн-версии произойдёт автоматически).

- **Android (Chrome):** откройте адрес приложения → меню `⋮` → **«Установить приложение»** → подтвердить.
- **iPhone/iPad (Safari):** откройте адрес → кнопка `Поделиться` → **«На экран "Домой"»** → Добавить.

После установки на иконке домашнего экрана приложение открывается как обычное и работает без сети.

## Обновление приложения

Замените файлы в репозитории сайта (Upload files работает и для обновления: перетащите новые
файлы, указывая «Overwrite»). При следующем открытии приложение получит новую версию
(service worker обновится автоматически). Если что-то не обновилось — удалите приложение с
телефона и установите заново.

## Замечание по безопасности

Токен даёт доступ к вашему репозиторию смет. Не сообщайте его никому. Для минимальных прав
используйте fine-grained токен, ограниченный только репозиторием `smeti-otoplenie-voda`.
